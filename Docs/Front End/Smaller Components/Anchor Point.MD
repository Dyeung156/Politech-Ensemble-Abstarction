# Anchor Point 
# Description 
An anchor point is used in Circle Visual to illustrate either the max or min of a cluster feature. It is placed on the outer edge of the Circle Visual, with the max present on the upper half and min in the lower half. 

It uses the Point interface to hold its coodinrates on the screen and for displaying the max / min. 

# Dependencies 
- Point Type (Util)
- React 
  - useRef
  - useEffect
- D3
