# Map Details Tab (Tab 3) 
# Description 
This tab will replace tab 2 after the user clicks on a cluster in tab 1. It holds the Map Details, which gives a detailed oversight on the maps in the cluster the user selects. 

The tab can be closed by the X symbol in the upper right.
