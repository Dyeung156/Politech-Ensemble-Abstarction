# Cluster Details Tab (Tab 2) 
# Description 
This tab will appear when the user hovers over a cluster in the circle visual. It houses cluster details to giver users an overview of the cluster they are currently hovering over. When the tab appears, it will share the screen with tab 1 using 50% of the screen width. 

This tab can be closed any time with either the user 
- moving the mouse off of the cluster in circle visual 
- the user clicking on the cluster

# Dependencies 
- React Redux 
    - useSelector 
    - RootState
    - cluster
- Cluster Details
